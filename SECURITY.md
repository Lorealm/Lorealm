# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

Please don’t report security vulnerabilities via GitHub issues, instead report them privately via the [Security Advisories](https://github.com/Lorealm/Lorealm/security/advisories/new) page.
