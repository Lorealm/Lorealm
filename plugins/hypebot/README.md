# HypeBot

A little robot that sits above the chat bar and reacts to your story, like NovelAI's HypeBot.

Click it to hear what it thinks of the latest scene. Each comment is a small request to one of your connection profiles, so a cheap, fast model suits it well.

## Settings

- **auto**: comment on every new reply, without a click.
- **profile**: the connection profile HypeBot asks. Leave it empty to use your active one.
- **prompt**: who HypeBot is and how it talks. It's given the last few messages of the story and answers with its comment.
